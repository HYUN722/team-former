# 팀 편성 웹 앱

학번 2601975 · 이름 정수현

학생들이 팀 프로젝트를 위한 팀을 스스로 편성하는 웹 앱입니다.
학생은 팀에 지원하고 기존 팀원의 투표로 합류가 정해지며, 모집 마감 뒤 팀이 없는 학생은
AI가 배정안을 제안하고 앱이 그 배정안을 규칙으로 검사한 뒤 관리자가 확정합니다.

### 필수 포함 역할 자리 계산

기획자와 웹 프로그래머는 **서로 다른 사람**이 맡아야 하므로, 한 학생이 둘 다 할 수 있어도 하나로만 셉니다.
사람-역할 이분 매칭의 최대 매칭 크기로 "이미 채운 필수 역할 수"를 구합니다 (`rules.covered_required_roles`).

```
남은 필수역할 수 = 2 - 이미 채운 필수역할 수
지원자를 넣은 뒤 남는 자리 = 4 - (현재 인원 + 1)
남는 자리 < 남은 필수역할 수  ->  막음
```

## 8. 파일 구성

```
streamlit_app.py   화면 (공고 2.7절의 Streamlit key 를 그대로 씀)
db.py              Supabase 연결과 질의. 연결 풀을 한 번만 만들어 재사용
rules.py           팀 규칙 판정. 화면/DB와 무관한 순수 함수
ai_assign.py       오픈라우터 호출, 3중 폴백, 완전 탐색 배정
schema.sql         테이블 생성 SQL (tf_ 접두사, 유일성 제약, 비밀번호 해시 열)
tests/test_rules.py  공고 부록의 연습용 시나리오로 규칙을 검증하는 시험
data/              연습용 시나리오 명단 CSV 3개
docs/              PRD, 구현 계획, 준비 순서
img/               README에 넣은 화면 캡처
```

## 9. 보안

- `OPENROUTER_API_KEY`, `DATABASE_URL`, `ADMIN_PASSWORD` 는 `.env`(로컬)와 Streamlit Secrets(배포)에만 둡니다.
  `.gitignore` 가 `.env` 를 걸러 내며, 코드에 값을 적지 않았습니다.
- 화면에는 키가 **있음/없음** 만 표시하고 값은 출력하지 않습니다.
- 비밀번호는 `bcrypt` 해시로 저장하고, 로그인할 때 해시를 비교합니다.
- 관리자 기능은 `is_admin` 인 계정만 볼 수 있습니다.
- 명단은 교수가 나눠 준 가상 학생만 씁니다.
