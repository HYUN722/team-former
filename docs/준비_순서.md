## 1단계. Supabase 프로젝트 만들기 (10분)

6장 실습에서도 **같은 프로젝트**를 씁니다. 무료 프로젝트는 2개까지만 만들 수 있으니 새로 더 만들지 마세요.

1. https://supabase.com 에서 GitHub 계정으로 로그인
2. **New project**
   - Name: `web-programming` (아무 이름이나 괜찮습니다)
   - **Database Password**: 여기서 정한 비밀번호를 꼭 따로 적어 두세요. 다시 볼 수 없습니다.
     - 특수문자 없이 영문+숫자로 만드는 게 편합니다(주소에 넣을 때 인코딩 문제가 없음)
   - Region: `Northeast Asia (Seoul)`
3. 프로젝트가 만들어질 때까지 2~3분 기다립니다

### DB 주소 복사 — ★ 여기가 제일 많이 틀리는 곳

4. 위쪽의 **Connect** 단추 → **Connection string** 탭
5. **Direct connection 을 쓰면 안 됩니다.** Streamlit Community Cloud는 IPv4만 쓰는데
   Direct connection은 IPv6 전용이라 배포하면 연결이 안 됩니다.
   → **Session pooler** 항목의 URI 를 복사하세요. (주소에 `pooler.supabase.com` 이 들어 있습니다)
6. 복사한 주소의 `[YOUR-PASSWORD]` 부분을 3번에서 정한 비밀번호로 바꿉니다

   ```
   postgresql://postgres.xxxxxxxx:내비밀번호@aws-0-ap-northeast-2.pooler.supabase.com:5432/postgres
   ```

### 테이블 만들기

7. 왼쪽 메뉴 **SQL Editor** → **New query**
8. 저장소의 `schema.sql` 내용을 전부 붙여 넣고 **Run**
9. 왼쪽 **Table Editor** 에서 `tf_` 로 시작하는 테이블 8개가 보이면 성공입니다

## 3단계. 내 컴퓨터에서 돌려 보기 (10분)

1. 저장소 폴더(예: 바탕화면의 `Study04_TeamFormer`)에 파일을 전부 넣습니다
2. 같은 폴더에 `.env` 파일을 만듭니다. `.env.example` 을 복사해 이름을 `.env` 로 바꾸면 됩니다

   ```
   OPENROUTER_API_KEY="sk-or-v1-받은키"
   DATABASE_URL="1단계에서 만든 주소"
   ADMIN_PASSWORD="정한관리자비밀번호"
   ```

   - ★ 파일 이름이 정확히 `.env` 여야 합니다. 메모장이 `.env.txt` 로 저장하면 키가 깃허브에 올라갑니다
   - ★ `.env` 파일을 두 번 눌러 열지 마세요
   - 메모장에서 저장할 때 "파일 형식: 모든 파일", 파일 이름에 `.env` 를 그대로 쓰면 됩니다

3. 터미널(PowerShell)에서 그 폴더로 이동한 뒤

   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   streamlit run streamlit_app.py
   ```

   macOS/Linux면 `source .venv/bin/activate` 입니다

4. 브라우저가 열리면 학번 `admin`, 비밀번호는 `ADMIN_PASSWORD` 에 적은 값으로 로그인
5. `data/쉬움.csv` 를 올리고 팀 수 3을 넣고 **명단으로 처음 상태 만들기**
6. 다른 브라우저 창(시크릿 창)에서 학번 `2026101`, 비밀번호 `1234` 로 로그인해 지원해 봅니다

## 5단계. Streamlit 배포 (15분)

1. https://share.streamlit.io 에 GitHub 계정으로 로그인
2. ★ 배포 **전에** 비공개 저장소를 읽을 권한을 줍니다
   - 오른쪽 위 프로필 → **Settings** → **Linked accounts**
   - **Private access** 옆의 **Connect here** 를 누르고 권한 허용
3. **Create app** → **Deploy a public app from GitHub**
   - Repository: 방금 만든 저장소
   - Branch: `main`
   - Main file path: `streamlit_app.py`
4. **Advanced settings** → **Secrets** 칸에 아래를 그대로 붙여 넣습니다(따옴표 포함)

   ```
   OPENROUTER_API_KEY = "sk-or-v1-받은키"
   DATABASE_URL = "1단계에서 만든 주소"
   ADMIN_PASSWORD = "정한관리자비밀번호"
   ```

   - 브라우저 자동완성이 예전 값을 채우면 지우고 다시 씁니다
5. **Deploy** → 2~3분 기다립니다
6. 배포가 끝나면 앱 메뉴 → **Settings** → **Sharing**
   - "Who can view this app" 을 **This app is public and searchable** 로 바꾸고 **Save changes**
7. ★ **시크릿 창**으로 배포 주소를 열어 로그인 화면이 보이는지 확인합니다
   (채점 프로그램은 로그인하지 않은 브라우저로 접속합니다)
